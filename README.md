# Gestión de un incidente de ciberseguridad

**Trabajo práctico individual · Proyecto en desarrollo**

Investigación y respuesta ante un incidente ficticio de phishing en una empresa de aproximadamente 100 empleados. El escenario incluye ejecución de un adjunto malicioso, alertas de antivirus, conexiones externas sospechosas, intentos de acceso a carpetas compartidas y una posible exposición de datos personales de clientes.

> **Importante:** el incidente es un caso propuesto. Las pruebas se realizarán con muestras inocuas y en máquinas virtuales Windows y Linux autorizadas. Los resultados reales del laboratorio se distinguirán de los datos hipotéticos.

## Metodología

1. Preparar y aislar el laboratorio de VirtualBox; registrar versiones, configuración y capturas.
2. Ejecutar prácticas autorizadas y reproducibles.
3. Guardar herramientas, comandos, fecha/hora, resultados y evidencias.
4. Distinguir **hechos del enunciado**, **hipótesis** y **observaciones verificadas**.
5. Desarrollar los seis apartados y entregar un informe técnico en PDF.
