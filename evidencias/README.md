# Evidencias

- `capturas/`: capturas de pantalla revisadas y anonimizadas.
- `resultados/`: resultados técnicos de laboratorio previamente saneados.
- `plantillas/`: fichas reutilizables de registro, práctica y custodia.

## Reglas
No fabricar evidencias ni presentar ejemplos como resultados obtenidos. Evitar datos personales, secretos, credenciales, direcciones internas sensibles y archivos potencialmente peligrosos. Anotar la fecha, fuente, herramienta, contexto e integridad.
